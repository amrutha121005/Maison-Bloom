# Maison Bloom 

A modern 3D café website built using HTML, CSS, JavaScript, and Three.js featuring immersive animations, floating 3D menu cards, aesthetic food visuals, and a luxury café UI experience.

## Features
- Interactive 3D Hero Section
- Floating Menu Cards
- Real Food Photography
- Smooth Animations
- Custom Cursor Effects
- Responsive Modern Design

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Three.js
